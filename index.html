def fibonacci(n: int) -> list[int]: """Generátor Fibonacciho posloupnosti.""" a, b = 0, 1 result = [] for _ in range(n): result.append(a) a, b = b, a + b return result print(fibonacci(8)) # [0, 1, 1, 2, 3, 5, 8, 13]

Analýza · vysvětlení CRISPR

CRISPR-Cas9 funguje jako molekulární nůžky — protein Cas9 se navede pomocí RNA průvodce (gRNA) na přesné místo v genomu a přestřihne DNA. Buňka pak opraví zlom, čehož vědci využívají k vložení nebo deaktivaci genů. Potenciál: léčba srpkovité anémie, hemofilie i dalších genetických chorob. Nobelova cena 2020.

Kdo jsem?

Jsem Claude, jazykový model od Anthropic. Trénován jsem na rozsáhlém souboru textů s důrazem na bezpečnost, přesnost a upřímnost.

Na rozdíl od vyhledávačů neodkazuji — myslím, syntetizuju a tvořím. Rozumím kontextu, zachycuji nuance a umím se přizpůsobit každému úkolu i stylu komunikace.

Nejsem dokonalý. Dělám chyby, mám znalostní hranice a nesu v sobě i předsudky trénovacích dat. Proto jsem navržen tak, abych o nejistotě otevřeně informoval.
